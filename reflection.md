# Course reflection
By: Daniel Bond

1. I think that the lexer/parser approach that we learned and used during the course is applicable and commonly used even outside compilers. Tokenization in itself is a big one, used nowadays in every LLM. The way combinations of tokens are interpreted into different nodes, and how they are defined in EBNF, is a great look into compiler inner works.
2. For some reason I expected this course to be about writing in assembly/LLVM, and I am pretty interested in that. Otherwise, I'd like to hear more on code optimizations, that's a great topic.
3. The split into front/middle/back end was quite a surprise, I expected some more direct approach, without relying on LLVM. Also, the fact that LLVM IR can be generated directly from code, without knowing LLVM, is an incredible thing. Lastly, the way the linker helps with resolving symbols from other files into one is a cool mechanism, though I already knew how it works from before. HM: phi stuff for if/else branches is fun.
4. To be fair, for the time allocated for this course, it has massive amount of content, along with detailed explanations and examples on lectures/practices (though nobody visits them).
5. Not sure if related to the course, I'd happily take a course from you on low level programming in C or ASM, as I think it would be a nice extension to what we already learned.
